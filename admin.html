# ชื่อผู้ใช้ (Username) อีเมล (Email) บทบาท (Role) จำนวนรายการ การจัดการ (Actions)
รายการทั้งหมดในระบบ (All Transactions)
ในฐานะ Admin สามารถดูรายการของผู้ใช้ทุกคน แต่ ผู้ใช้ทั่วไปเห็นเฉพาะรายการของตัวเองเท่านั้น
วันที่ ชื่อรายการ หมวดหมู่ ประเภท จำนวนเงิน เจ้าของบัญชี การจัดการ
เพิ่มผู้ใช้ใหม่
แก้ไขข้อมูลผู้ใช้
ระบบป้องกันการโจมตี (Web Security Defense)
มาตรฐานความปลอดภัย 10 คะแนนเต็ม (ตรวจในห้องเรียน) — อิงสไลด์ อ.จตุภูมิ จวนชัยภูมิ
1. XSS Protection (สไลด์หน้า 5-13)
Cross-Site Scripting (CWE-79)

แปลงอักขระพิเศษเป็น HTML Entities < > " ' / ( ) ป้องกัน Hacker ฝังโค้ด JavaScript ทั้ง Stored XSS และ Reflected XSS

✓ ฟังก์ชัน escapeHtml() & secureStr()
✓ ป้องกัน Script Injection ทุกจุด
2. SQL Injection (สไลด์หน้า 14-18)
SQL Injection (CWE-89)

ป้องกันการ Bypass Login ด้วย ' OR 'x'='x หรือ admin' or ''='' ; #

✓ ใช้ PDO Prepared Statements (:param)
✓ รหัสผ่านเข้ารหัสด้วย BCRYPT (password_hash)
3. MITM Protection (สไลด์หน้า 19-21)
Man-In-The-Middle Attack

ป้องกันการดักจับข้อมูลชื่อผู้ใช้และรหัสผ่านผ่านเครือข่าย

✓ ทำงานบนโปรโตคอล HTTPS / SSL (TLS 1.3)
✓ ทำงานร่วมกับ Captcha ป้องกันการสวมรอย
4. SPAM & Bot (สไลด์หน้า 22-25)
SPAM & Automated Bots

ป้องกันบอทส่งข้อความขยะหรือยิงบันทึกรายการอัตโนมัติ

✓ Dynamic Captcha ยืนยันตัวตนมนุษย์
✓ Rate Limiting (จำกัดระยะห่างเวลาโพสต์)
เกณฑ์ความปลอดภัยครบถ้วน 10 คะแนนเต็ม
